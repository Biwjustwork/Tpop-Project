# Neon Lane Racer

เอกสารอธิบายรายละเอียดและการทำงานของมินิเกม **Neon Lane Racer** ในโฟลเดอร์ [`game_folk`](file:///D:/Project/Tpop-Project/games/game_folk)

---

## About the game
**Neon Lane Racer** เป็นมินิเกมแนวขับขี่บิ๊กไบค์หลบสิ่งกีดขวางบนถนนทางหลวงยามค่ำคืน พัฒนาโดย **ศรัณย์ กระจ่างแก้ว (โฟล์ค - 193)** ผู้เล่นรับบทเป็นนักบิดที่ต้องควบคุมรถบิ๊กไบค์คู่ใจซิกแซ็กสลับเลนเพื่อหลบหลีกรถยนต์คันอื่นๆ ที่แล่นย้อนศรหรือแล่นช้ากว่าบนถนน โดยเป้าหมายคือการรักษาระยะทางและเอาชีวิตรอดให้ได้นานที่สุด ความเร็วของตัวเกมจะทยอยเพิ่มขึ้นตามระยะทางที่วิ่งได้เพื่อท้าทายฝีมือของผู้เล่นอย่างต่อเนื่อง

---

## Genre & Visual Style
- **Genre**: Endless Runner / Lane-switching Arcade Racer (แนวขับรถสลับเลนแบบไม่สิ้นสุด)
- **Visual Style**: แนว **Cyberpunk / Synthwave (Neon Aesthetic)** โทนสีหลักใช้สีมืดลึกของท้องฟ้าและถนน (Deep Navy & Midnight Asphalt) ตัดกับแสงสีนีออนเปล่งประกายอย่าง สีส้มอมแดง สีฟ้ามินต์ สีเหลืองอำพัน และสีแดงสะท้อนแสง มีการจำลองฉากหลังตึกระฟ้า (Scrolling Skyline Backdrop) ที่เคลื่อนที่ด้วยมิติความเร็วต่างจากถนน (Parallax-like feeling) และระบบหน้าต่างอาคารที่สุ่มติดและกะพริบเบาๆ นอกจากนี้ยังใช้ฟอนต์ล้ำยุคอย่าง `Orbitron` และ `Share Tech Mono` จาก Google Fonts เสริมให้ได้อารมณ์ Sci-Fi สไตล์ Arcade ยุค 80s

---

## Gameplay Mechanics
- **Controls (การควบคุม)**:
  - กดปุ่มลูกศร **ซ้าย / ขวา (Arrow Left / Arrow Right)** หรือปุ่มตัวอักษร **A / D** เพื่อเปลี่ยนช่องทางวิ่ง (มีทั้งหมด 3 เลน)
  - รองรับการคลิกเมาส์/สัมผัสหน้าจอ (Mouse Click / Touch Tap) สำหรับปุ่มเลือกความยากในหน้าเมนูหลัก และกดเริ่มเล่นใหม่ในหน้าจอดับ (Game Over Screen)
- **Smooth Lane Changing & Leaning (ระบบการเคลื่อนที่และการเอียงตัว)**:
  - การขยับเปลี่ยนเลนใช้หลักคณิตศาสตร์แบบ interpolation (Linear Interpolation / Lerp) ทำให้ตัวรถไม่ได้เปลี่ยนตำแหน่งในทันที แต่จะค่อยๆ สไลด์เข้าเลนใหม่อย่างนุ่มนวล
  - เพิ่มมิติการเคลื่อนที่ด้วย **Lean Effect** (การเอียงรถ) โดยองศาของรถจะเอียงไปตามทิศทางที่เปลี่ยนเลนชั่วขณะ และจะกลับมาตั้งตรงเมื่อตัวรถจอดตรงกึ่งกลางเลน
- **Difficulty Settings (โหมดความยาก)**:
  - **EASY (Calm Traffic)**: ความเร็วเริ่มต้นต่ำ ($3.2$), ความเร่งเพิ่มขึ้นช้า (เพิ่มความเร็วทุกๆ $160$ เมตร), อัตราการเกิดรถคันอื่นช้า และโอกาสเกิดรถยนต์มาพร้อมกัน $2$ เลนพร้อมกันมีเพียง $18\%$ เท่านั้น
  - **HARD (Rush Hour)**: ความเร็วเริ่มต้นสูงขึ้น ($5.2$), ความเร่งเพิ่มขึ้นเร็วเป็นสองเท่า (เพิ่มความเร็วทุกๆ $90$ เมตร), อัตราการเกิดรถคันอื่นเร็วขึ้นมาก และโอกาสเกิดรถพร้อมกัน $2$ เลนพร้อมกันสูงถึง $55\%$ ซึ่งบีบให้ผู้เล่นต้องตัดสินใจอย่างรวดเร็ว
- **Scoring (ระบบคะแนน)**:
  - ระยะทางสะสมจะปัดเศษทศนิยมเป็นจำนวนเต็มบวกในหน่วยเมตร ($m$) ซึ่งจะเพิ่มขึ้นอย่างต่อเนื่องสัมพันธ์กับความเร็วของรถบิ๊กไบค์ ยิ่งผู้เล่นทำเวลาได้นานความเร็วก็ยิ่งสูง ทำให้คะแนนวิ่งไวขึ้นอย่างทวีคูณ
- **Collision Detection (การชนและการสิ้นสุดเกม)**:
  - ตรวจจับการชนด้วยอัลกอริทึม AABB Collision Detection (ตรวจกรอบสี่เหลี่ยมรอบตัวรถ) หากกรอบของบิ๊กไบค์เข้าไปซ้อนทับกับกรอบของรถยนต์คันใดคันหนึ่ง ตัวเกมจะหยุดทำงาน และแสดงผลหน้าจอสีแดง "CRASHED" พร้อมระยะทางที่ทำได้ และตัวเลือกในการเล่นซ้ำ (RETRY) หรือกลับสู่เมนูหลัก (MENU)

## Tech Stack
- **HTML5**: โครงสร้างไฟล์แบบ Single Page (SPA) และคอนเทนเนอร์เก็บ Canvas
- **CSS3 (Vanilla CSS)**: ออกแบบหน้าจอโดยใช้คุณสมบัติของ Flexbox, Gradients เพื่อทำสีท้องฟ้านีออน, การดึง Font ผ่าน Google Fonts Web-interface, และตกแต่งขอบคอนเทนเนอร์ด้วย Glassmorphism กับ Clip Path เป็นกรอบเหลี่ยมสไตล์ไซเบอร์พังค์
- **JavaScript (Vanilla JS - ES6)**: ควบคุมตรรกะเกมทั้งหมด ได้แก่ ฟังก์ชันสำหรับฟิสิกส์การอัปเดตตำแหน่ง, การคำนวณอัตราความยากของแต่ละโหมด, การสุ่มสีรถยนต์ในฉาก และการประมวลผลชนสิ่งกีดขวาง
- **HTML5 Canvas 2D API (`CanvasRenderingContext2D`)**: วาดองค์ประกอบกราฟิก 2D ทั้งหมดแบบสด เช่น ถนน, เส้นประสะท้อนแสงบนถนน, ตึกระฟ้า, เงารถยนต์, เอฟเฟกต์ไฟหน้ารถ (Light Beam Projection Gradient), รถมอเตอร์ไซค์ และปุ่มกด
- **Game Loop Interface**: ใช้ `requestAnimationFrame` ในการสร้างลูปการเล่นเกมหลัก ทำให้ภาพลื่นไหลสูงสุดที่ระดับ 60 FPS ขึ้นกับความถี่การแสดงผลของหน้าจอ
