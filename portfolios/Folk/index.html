Rust Lua LZMA

Reaper Obfuscator

Production-grade Lua 5.1 obfuscator built in Rust using a Luraph-style architecture. Compiles source to bytecode, LZMA-compresses it, Base85-encodes the payload, and wraps everything in a self-contained Lua loader. Ships with a web UI backed by a Monaco editor.
